# MeetScribe web UI

This repository only hosts the built web interface of MeetScribe, published at
https://echo-sculpture.github.io/meetscribe/ . The page is a front end for the
MeetScribe gateway running on the owner's own computer; it does nothing on its
own and requires signing in to that local gateway.
